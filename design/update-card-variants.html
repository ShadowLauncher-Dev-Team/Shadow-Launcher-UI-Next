更新卡片设计稿 · v2（按代码真实语义重写）

左侧统一启动器图标；文案不再抄参考图，逐字对齐 UpdateManager + quitForUpdate()。
先把两个问题用代码回答掉：
1. 下载确实在启动器内发生。UpdateManager 用 HttpClient 把安装包下到 _update/，并发 downloadProgress(received,total) → 后端 updateDownloadProgress。 但 QML 从来没接这个信号（全项目 0 处引用），所以你从没在界面上见过下载进度 —— 这也正是“何来下载这个步骤”的来源。
2. 不是自动重启。下载完成 → downloadComplete + updateAvailableForInstall(version) → QML updateReadyForRestart 弹常驻提示「更新已就绪：vX，点击立即重启安装」；点了 quitForUpdate() 才 startDetached 新进程（PreInit 见 state.json=Ready → 解压 → SLUpdater 装机 → 重启），旧进程 500ms 后退出。不点也行，下次启动会自动装。
所以我上一稿里“更新完成后将自动重启应用”是照抄参考图的错文案，右边那个按钮也不是多余 —— 它是唯一真正触发安装的入口。
