## 1. 启动配置（最复杂）

总开关 `配置模式 = 跟随全局设置 / 独立配置`，文案：
- 跟随：「当前跟随全局默认，切换上方『独立配置』后可单独设置本版本」
- 独立：「此版本使用独立配置，不受全局设置影响」

**逐项接口（`shadow_backend.h` / `settings_backend.h`）**

| 控件 | 后端 |
|---|---|
| Java：自动（推荐） | `versionJavaMode(id)=0`；推荐大版本由 MC 版本推（旧 UI 文案「MC 1.20.1 → 推荐 Java 17+」） |
| Java：指定 | `versionJavaMode=idx` + `availableJavaList()` / `selectJavaByIndex` / `scanJavaInstallations()`（异步）/ `pickJava()`（文件对话框） |
| Java：用版本文件夹里的 Java | 旧 UI 有此项，**后端无接口**（见缺口 2） |
| JVM 参数 | `versionJvmArgsMode` / `versionJvmArgs`；旧 UI 有 6 个预设（自动 / G1GC 平衡 / Parallel 吞吐 / ZGC 低延迟 / 分代 ZGC 优先 / 仅 G1GC）+「恢复默认 JVM」「清空」+ GC 冲突检测 |
| GC 策略 | `versionGcMode`（0=跟随，1..3 覆盖） |
| 全屏启动 | `versionFullscreenMode/versionFullscreen` |
| 强制独显 | `versionHighPerfGpuMode/versionHighPerfGpu` |
| 窗口标题 | `versionWindowTitleMode/versionWindowTitle`（空=不修改） |
| 自动进服 | `versionAutoJoinServer`（空=不自动） |
| 启动前 / 退出后命令 | `versionPreLaunchMode/…Command`、`versionPostExitMode/…Command`（异步，不阻塞） |
| 游戏附加参数 | `versionGameArgsMode/versionGameArgs` |

**`resolvedXxx` 一族（v1 漏掉的，`shadow_backend.h:386-396 / 657-678`）**：
`resolvedGcMode / resolvedAutoJoinServer / resolvedFullscreen / resolvedWindowTitle / resolvedPreLaunchCommand / resolvedPostExitCommand / resolvedMemoryMB / resolvedJvmArgs / resolvedGameArgs / resolvedHighPerfGpu`
→ 返回"跟随全局之后真正生效的值"，**直接就是 C 版右侧预览的数据源**，不用前端自己拼。

## 9. 真正缺的（只有 6 条）

1. **「配置模式」批量开关**：没有一次性把 11 个 mode 置 0/1 的接口 → 建议 `setVersionUseGlobal(id, bool)`，否则"切独立配置"要前端连调 11 次。
2. **「使用版本文件夹中的 Java」**：旧 UI 有，后端无。
3. **覆盖项汇总**：建议 `versionSettingsSummary(id)` 一次返回 {覆盖了哪几项, resolved 值}，避免进页面 11+10 次跨语言调用。
4. **JVM 预设表**：旧 UI 前端拼字符串 → 建议后端给 `jvmPresets()`，否则新旧 UI 各拼一套、容易不一致。
5. **按版本的分辨率**：只有全局 `windowWidth/Height`（per-version 只有全屏）。
6. **版本图标 / 显示名**：未暴露（`renameVersion` 改的是 id）。

## 10. 对设计的直接影响

1. **必须有 8 项导航**（v1 的 5 组表单不够），且「Mod 管理」要按 loader 条件隐藏。
2. 启动配置区用**总开关（配置模式）**当主控，逐项开关只在"独立配置"时展开——比 v1 的"每行一个继承开关"省一半字。
3. **`resolvedXxx` 让「预览」成为真实功能**：C 版右侧合成值不是概念，直接绑这些接口。
4. Mod / 资源包 / 存档 是**列表型页面**（搜索 + 行 + 行内开关 + 批量条），与表单区不同构，三版都要给它们留独立形态。
5. 危险操作（删除版本、删除存档、覆盖导出）必须二次确认；导出脚本必须带凭据警告条。
