## 0. 五条否决意见的根因（逐条认领）

| 用户意见 | 根因 | 正确做法 |
|---|---|---|
| ① 菜单栏不是"真正收回"，像重新载入 | 我自作主张把侧栏改成 56px 图标条（rail），另起一套布局。项目约定里全屏页是**侧栏宽度收到 0** + 页面淡入右移 24px（`StageShell.qml:9 / 105-118`，`Theme.durPage=320 / easeEnter=OutQuint`） | 下载页按版本页/账户页同一套 host 模式：`sideBar.width → 0`，DownloadPage `anchors.fill` 全窗，淡入 + 右移 24px；子导航由页面内部承载 |
| ② 四周边距太窄、无呼吸感 | 我用了 22px 边距。DESIGN_SPEC §3 规定 1375 宽下内容左右 64、底部 58，顶栏高 52；800×550 用 28/24 | 页面统一 64/52/58，小窗 28/24/46 |
| ③ 「已安装」分组下每行又标「已安装」 | 分组标题已给出结论，行内重复 | 行内只保留版本号 + 类型 + 右箭头；已安装状态只在筛选计数/高亮卡里体现 |
| ④ 安装配置完全自设计，没参考原 UI | 我做成"chip 横排 + 手输版本号"，与原实现不同。原 UI 是**每个加载器一张可展开卡片**（Forge / NeoForge / Fabric / Fabric API / OptiFine，`InstallPage.qml:478-563`），未选中时给禁用理由；MC 版本是一张卡（版本号 + 安装名称输入 + 冲突提示，`:413-469`）；底部固定操作栏「开始下载」 | 按原结构重建，只换新 UI token |
| ⑤ 分组列表与原设计不符 | 原下载页是「7 个 tab pill + 带计数的筛选 pill（正式版/快照版/远古版/愚人节版）+ 最新正式版高亮卡(72px) + 42px 卡片列表」，不是"已安装/可下载"分组 | 恢复原结构 |

## 1. 旧 UI 现状（事实，带行号）

### 下载页 `qml/DownloadPage.qml`
- 顶部 tab bar：7 项 pill（MC 版本/Mod/光影/资源包/整合包/数据包/Java），高 34，选中项 accent 底 + 1px 边框（`:355-435`）
- 筛选 pill：图标 + 文案 + 数量，高 30、圆角 15，选中 accent 实心（`:457-512`）
- 最新正式版高亮卡：高 72，左侧「最新正式版」小标题 + 版本号大字，右侧「安装」入口（`:531-617`）
- 版本列表：`ListView spacing:2`，delegate `VersionCard` 高 42（`:618-644`）
- 点击卡片 → 打开全屏 `InstallPage`（`:630-639`）

### 版本卡 `qml/VersionCard.qml`
- 高 42、圆角 radiusMd；左版本号（fontSizeMd）+ 右类型标签（正式版/快照/愚人节/旧版，18 高）
- 悬停 accent 微光；选中 1.5px accent 边框

### 安装页 `qml/InstallPage.qml`
- 顶部返回栏高 44（`:369`），滚动内容内边距 16、卡片间距 12，滚动条 6px
- CARD 1「Minecraft 1.20.1」高 96（冲突时 116）：版本号大字 + 安装名称 `TextInput`(32 高) + 冲突提示（`:413-469`）
- 「Mod 加载器」小标题 + 每个加载器一张 `ModLoaderCard`（Forge / NeoForge / Fabric / Fabric API / OptiFine），卡内是版本列表；未选中时给禁用理由（"NeoForge 已选中"/"Fabric 不兼容 Optifine"）
- 光影（高清修复）段：OptiFine 卡片
- 底部固定操作栏：「开始下载」（`:765`）

### 新 UI 壳 `ui/StageShell.qml`
- 全屏页统一模式：侧栏 `width: fullOpen ? 0 : sideW`，页面 opacity 0→1（durBase）+ Translate x 16→0（durPage）
- 内容页不透明底必须自己铺（否则启动页透出）

## 2. 重构方案（待确认后实施）

### 2.1 页面关系

```
StagePage（启动）
 ├─ 点侧栏「下载」→ downloadOpen
 │    DownloadHost（全窗 anchors.fill，侧栏宽度→0，页面淡入+右移24）
 │      ├─ 列表态：DownloadListPage（tab pills + 筛选 pills + 最新版高亮 + 卡片列表）
 │      ├─ 配置态：InstallConfigPage（从右滑入 24px；顶部返回栏 + 卡片分段 + 底部固定操作栏）
 │      └─ 进度态：DownloadProgressPage（原 InstallProgressPage 结构：任务列表 + 单任务进度；顶部汇总条保留"总进度/总速度"）
 └─ 点其它主项 → downloadOpen=false，侧栏宽度回来
```

### 2.2 尺寸（严格照 DESIGN_SPEC）

| 位置 | 1375 × 897 | 800 × 550 |
|---|---|---|
| 侧栏 | 收起为 0 | 0 |
| 页面左右内边距 | 64 | 28 / 24 |
| 顶栏高 | 52（右侧留 104 给窗口按钮） | 46（留 96） |
| 内容块间距 | 24 / 16 / 12 / 8 | 16 / 12 / 8 |
| 卡片高 | 版本卡 48（原 42 → 新 UI 字号略大） | 44 |
| 底部操作栏 | 高 72，内边距左右 64 | 64 |

### 2.3 列表页（对齐原结构）

- 标题「下载」+ 上方 tab pills（7 项，高 34；未接入的 tab 先显示占位空态，不画假内容）
- 筛选 pill 行：正式版(数量) / 快照版(数量) / 远古版(数量) / 愚人节版(数量)；右侧「刷新」按钮
- 最新正式版高亮卡：72 高，左「最新正式版」+ 版本号 26px，右「安装」箭头
- 版本卡片列表：48 高，左版本号 15px，右类型标签 + 箭头；已安装版本在版本号后加一个 4px 绿点（唯一标记，不再有文字）
- 点卡片 → 配置态

### 2.4 配置页（对齐原 InstallPage）

- 顶部返回栏 44：左「← 返回下载」
- CARD 1：版本号 30px + 安装名称输入（默认版本号）+ 冲突提示
- CARD 2「Mod 加载器」：Forge / NeoForge / Fabric / Fabric API（仅 Fabric 选中时出现）/ OptiFine，每张卡显示加载器名 + 版本选择行 + 禁用理由（不满足时置灰并显示原因）
- CARD 3「Java」：显示将使用的 Java（只读；异常时给修复入口）
- 底部固定操作栏：左「安装名称/目标目录」摘要，右「开始安装」主按钮（唯一实心按钮）

### 2.5 动效（第一版就要有，因为"收回"本身是动效）

- 进入下载：侧栏 0（durPage 320 / OutQuint）+ 页面 opacity 0→1（durBase 180）+ x 16→0
- 列表 → 配置：配置页 x 24→0 + opacity，列表页 x 0→-16 + opacity 0（同 durPage）
- 配置 → 返回：反向
- 进度页：从下浮起 24px，与账户页一致
- 禁止 SpringAnimation（DESIGN_SPEC §6.5）

### 2.6 验收 rubric（照抄 DESIGN_SPEC §7，12 项 100 分）

首屏容器型元素 ≤1；空白能说出理由；同列共享左边线；到窗口边距离只用 3 种值；1375 与 800 同一构图。
