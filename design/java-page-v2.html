Java 下载页 · 方案 A 配色修订

同一个布局，只换调色与字体观感。蓝色从「到处都是」收回到三个位置：主按钮、进度条、当前步骤的下划线。
上一版为什么"蓝不拉几"：选中态是蓝底 + 蓝边（#132340 / #1f3a63），副文案和"已选/下一步"用浅蓝（#a9c8ff）， 步骤圆圈、扩展名方块、"启动器托管"小卡也全是蓝的 —— 一屏里出现 7 处蓝，强调就等于没有强调， 而且深蓝底上的浅蓝小字在雅黑下会显得发灰、发脏。
这一版：选中态改成中性提亮 + 左侧 2px 蓝条；所有次要文字降到中性灰（不带蓝）； 蓝色只剩主按钮、进度填充、当前步骤下划线；步骤圆圈用灰阶区分完成 / 进行中。

方案 A-1 · 石墨中性（推荐）

纯中性灰，接近 Linear / Vercel 的深色底。蓝色只做信号，不铺面。

方案 A-2 · 冷灰克制

保留一点冷调（跟启动器现有 Theme 一致），但取消蓝底与浅蓝小字。

方案 A-3 · 暖灰无蓝

完全不用蓝色：主按钮改成暖白实心、黑字，进度条同色。整体更"工具"、更沉。
