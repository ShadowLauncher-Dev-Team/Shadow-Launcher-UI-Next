# 繁体中文翻译术语表（港澳 / 台湾）

> 本文件是 `ui/` 界面文案翻译的唯一口径。**所有译文必须逐条人工判断，禁止机翻，禁止单纯做简体→繁体字符转换。**

## 一、两套繁体的关系

- `zh_HK`：港澳（香港 / 澳门）书面语习惯
- `zh_TW`：台湾书面语习惯

**大部分词两套相同，差异集中在少数科技用词上。差异表见第二节，必须严格执行。**

## 二、港澳 vs 台湾 差异表（强制）

| 简体（源） | zh_HK（港澳） | zh_TW（台湾） |
|---|---|---|
| 网络 | 網絡 | 網路 |
| 局域网 | 區域網絡 | 區域網路 |
| 软件 | 軟件 | 軟體 |
| 硬件 | 硬件 | 硬體 |
| 账号 | 帳戶 | 帳號 |
| 账户 | 帳戶 | 帳戶 |
| 质量 | 質素 | 品質 |
| 上传 | 上載 | 上傳 |
| 打印机 | 打印機 | 印表機 |
| 在线 | 線上 | 線上 |
| 视频 | 影片 | 影片 |

> 其余科技词两地通用：檔案 / 預設 / 儲存 / 設定 / 介面 / 記憶體 / 支援 / 程式 / 伺服器 / 快取 / 滑鼠 / 螢幕 / 載入 / 執行 / 搜尋 / 使用者 / 權杖 / 連接埠 / 疑難排解。

## 三、通用规则

1. **逐条翻译**：结合上下文判断，不逐字替换。例如「启动游戏」是「啟動遊戲」，「启动器」是「啟動器」。
2. **不要翻译的**：
   - 品牌名 `SHADOW`、`Shadow Launcher`（可保留英文）
   - 第三方产品名：`Minecraft`、`Forge`、`Fabric`、`NeoForge`、`OptiFine`、`Java`、`Mod`、`PCL2`、`HMCL`、`littleskin`
   - 技术标识：URL、路径、文件名、注册表键、命令行参数（`--ui-prefs` 等）、选项字符串（`options.txt` 的内容值）
   - 版本号、数字、单位符号（MB / GB / ms / FPS）
   - 日志与调试字符串（`console.info`、`qCInfo` 里的内容）
3. **占位符**：源文里的 `%1` `%2` 必须原样保留，位置可按语序调整。
4. **标点**：用全角；引号优先「」；括号用（）；省略号用……；**不要用半角逗号句号**。
5. **长度**：按钮/标签尽量不超过原文 1.4 倍宽度，否则界面会被撑破（尤其侧栏、按钮、卡片标题）。
6. **语气**：与简体版一致——简洁、不说教、不用感叹号堆砌。

## 四、既有约定（务必沿用）

- 「启动」→ 啟動（导航、按钮通用）
- 「下载」→ 下載
- 「联机」→ 連線
- 「设置」→ 設定
- 「下载进度」→ 下載進度
- 「帮助文档」→ 說明文件
- 「版本」→ 版本
- 「整合包」→ 整合包（台湾亦用「整合包」，不用「模組包」）
- 「模组」→ 模組
- 「光影」→ 光影
- 「资源包」→ 資源包
- 「数据包」→ 資料包
